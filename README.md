# Math & Physics Projects

Programs I've written to apply mathematics and physics I've studied independently, including linear algebra, probability and statistics, and Lagrangian mechanics.

| Project | Language | What it does |
|---|---|---|
| [Double-Pendulum Simulation](double-pendulum/) | Python | Derives the equations of motion with Lagrangian mechanics, then simulates and animates the chaotic motion |
| [Matrix Multiplication from Scratch](matrix-multiplication/) | C++ | Multiplies any two compatible matrices without external libraries |
| [Coin-Flip Distribution Simulator](coin-flip-distribution/) | Python | Shows the binomial distribution approaching a normal curve over 1,000 trials |
| [Law of Large Numbers Simulation](law-of-large-numbers/) | Python | Shows the proportion of heads settling toward 0.5 as flips accumulate |

## Requirements

The Python projects use NumPy, SciPy, and Matplotlib:

```
pip install numpy scipy matplotlib
```

The C++ project needs only a standard C++ compiler (such as g++).
